Kitchen Visual Safety Assistant

Review, verify, improve

Review visible head covering in a marked food-preparation work area, and possible objects blocking a marked walkway. An image produces review candidates; recorded video can check persistence. No overall “safe kitchen” verdict is produced.

2 · Mark preparation and walkway areas

Draw rectangles by dragging. The preparation area should cover where staff stand and work, not only the countertop. Only people whose box center falls inside it receive head-covering review. Set floor contact to “no” for countertop objects.

Improve the model with verified kitchen examples

Draw tight head boxes with “hairnet” or “no_hairnet” using Draw object / head box. Only manually drawn head labels enter a training export. Do not guess when a head is hidden. Exports containing uncertain head boxes are rejected.

Use the same session ID for frames from the same recording. Keep entire sessions in one split to reduce leakage. Predictions and illustrated scenes are not verified training data.
